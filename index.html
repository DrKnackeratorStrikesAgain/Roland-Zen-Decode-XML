Roland Zen Decode XML

Decodes Roland editor XML (ZenCore, Jupiter-X/Xm, Juno-X, Verselab MV-1, MC-101/707 etc.) into reference tables and structured data: byte layout, SYSEX offsets, and parameter metadata.

Note: Concrete SYSEX is now in the Decoded Reference section below and the generated data files.

Source code & generator: github.com/DrKnackeratorStrikesAgain/Roland-Zen-Decode-XML. See the README for more information.

JSON / JS / Python / C header exports are in the repository under out_* directories; they are not listed in this folder but are produced by the same pipeline documented in the README.

Decoded Reference

  • jupiter.html — Jupiter-X / ZenCore-oriented decode
  • juno.html — Juno-X editor XML decode
  • mv_1_180_A.html — I think this the best one for MV-1 and MC-101/707 (though 101/707 has no Project2)
  • mv_1.html
  • mv_1_180_B.html

Differences

  • jupiter_juno_diff.html — Differences between Jupiter and Juno
  • mv_1_180_A_jupiter_diff.html — Differences between MV-1-180-A and Jupiter
  • mv_1_180_A_juno_diff.html — Differences between MV-1-180-A and Juno
